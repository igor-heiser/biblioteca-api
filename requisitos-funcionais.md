# Requisitos Funcionais - Sistema de Biblioteca

| Código | Requisito Funcional      | Descrição                                                                 |
|--------|---------------------------|----------------------------------------------------------------------------|
| RF01   | Cadastro de Livros        | O sistema deve permitir cadastrar um novo livro.                          |
| RF02   | Listagem de Livros        | O sistema deve permitir consultar todos os livros cadastrados.            |
| RF03   | Consulta de um Livro      | O sistema deve permitir consultar um livro específico pelo seu ID.        |
| RF04   | Pesquisa de Livros        | O sistema deve permitir pesquisar livros pelo título.                     |
| RF05   | Ordenação de Livros       | O sistema deve permitir listar os livros em ordem alfabética pelo título. |
| RF06   | Edição de Livros          | O sistema deve permitir editar as informações de um livro cadastrado.     |
| RF07   | Exclusão de Livros        | O sistema deve permitir excluir um livro do sistema.                      |
| RF08   | Cadastro de Usuários      | O sistema deve permitir cadastrar, consultar, editar e excluir usuários.  |
| RF09   | Registro de Empréstimos   | O sistema deve permitir registrar o empréstimo de um livro a um usuário.  |
| RF10   | Consulta de Empréstimos   | O sistema deve permitir consultar os empréstimos realizados, incluindo devoluções. |
